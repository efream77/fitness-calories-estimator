# Fitness Calorie Estimator Web App

This web app predicts calories burned based on user input for age, gender, height, weight, duration, heart rate, body temperature, and activity type.

# Features
- Random Forest model for accurate predictions
- Interactive Plotly chart of calories vs duration
- Dynamic activity options based on dataset

# How to Run
1. Install dependencies:
    pip install -r requirements.txt
2. Run the Flask app:
    python app/app.py
3. Open browser at 'http://127.0.0.1:5000/' and input your data.
